# AffinityGeo brand kit

One Affinity template produces every icon and image the app and installer need.

## Workflow

1. Open the Affinity template (the maintainer keeps it outside the repository, because Affinity documents record the folder they were saved in). To make your own, create one artboard per image below, named exactly as listed.
2. Design the mark on **icon-1024**. Everything else can be generated from it.
3. Hand-tune the small sizes (**icon-32**, **icon-24**, **icon-16**): simplify the shapes and align them to the pixel grid so they stay crisp. The other sizes are optional.
4. File > Export, all artboards as PNG (and **logo-topbar** also as SVG), into `assets/brand/export/`. Keep the artboard name as the file name, for example `icon-32.png`. Affinity may add a suffix; that is fine.
5. Run `npm run icons`. It lists which sizes it generated by downscaling and which were hand-made.
6. Run `npm run dist` to build the installer with the new icons.

The raw exports in `assets/brand/export/` stay uncommitted. The generated files in `apps/desktop/build/` and `docs/brand/` ARE committed, so GitHub release builds carry the icon. After each design change, run `npm run icons` and commit those files.

## Artboards

| Artboard | Size | Purpose |
| --- | --- | --- |
| icon-1024 | 1024 x 1024 | Master icon (required); source for any missing smaller size |
| icon-256 | 256 x 256 | Largest entry in the Windows icon (Explorer, large views) |
| icon-128 | 128 x 128 | Windows icon, extra-large views |
| icon-64 | 64 x 64 | Windows icon, high-DPI shortcuts |
| icon-48 | 48 x 48 | Windows icon, desktop and Explorer |
| icon-32 | 32 x 32 | Windows icon, taskbar and lists (hand-tune) |
| icon-24 | 24 x 24 | Windows icon, small taskbar (hand-tune) |
| icon-16 | 16 x 16 | Windows icon, title bar and tiny lists (hand-tune) |
| logo-topbar | 24 x 24 | The logo in the app's top bar; also export as SVG |
| installer-sidebar | 164 x 314 | Left panel on the installer's welcome and finish pages |
| installer-header | 150 x 57 | Banner image on the installer's inner pages |
| social-preview | 1280 x 640 | GitHub social preview image |

## Outputs

- `apps/desktop/build/icon.ico` (16, 24, 32, 48, 64, 128, 256) and `icon.png`: picked up by electron-builder for the exe, shortcuts and installer.
- `apps/desktop/build/installerSidebar.bmp` and `installerHeader.bmp`: the NSIS installer pages (24-bit, flattened onto white).
- `docs/brand/social-preview.png` and `docs/brand/logo-topbar.svg`.
